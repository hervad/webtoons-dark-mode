# Security policy

## Supported versions

Only the latest version gets fixes. The userscript and the Toonlight extension update automatically, so please check that you're on the newest one (see [Releases](https://github.com/hervad/webtoons-dark-mode/releases)).

## What the script does and doesn't do

The theme runs only on `www.webtoons.com` and `m.webtoons.com`. It stores its own settings (dark mode, reader dim, edge shading, the scroll-to-top choice and whether you were logged in on the last page), makes no network requests of its own, and sends no data anywhere. The only change to what a page loads is a sharper size of the reader's ranking covers, from Webtoons' own image server.

## Reporting a problem

If you find a security issue (for example, a way for a page to make the script do something it shouldn't), please report it **privately** through [Report a vulnerability](https://github.com/hervad/webtoons-dark-mode/security/advisories/new) instead of opening a public issue. You'll get a reply as soon as possible, and the fix will ship as a new version.
